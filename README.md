# 📡 BT-SILENT — Bluetooth Auto Jammer

> ⚠️ **EDUCATIONAL PURPOSES ONLY**
> Unauthorized use against devices you do not own is ILLEGAL.
> This tool is for testing your own devices only.

Automatically scan and disrupt Bluetooth connections within range — **completely silent, no user input required.**

---

## ✅ Features
- 🔍 **Auto-scans** nearby Bluetooth devices continuously
- 📡 **Auto-attacks ALL devices** found — no MAC entry needed
- 🤫 **Quiet mode** — no output, no prompts, runs in background
- 🔄 **Auto-reconnect** — attacks new devices as they appear
- ⚡ **Zero dependencies** — uses built-in Linux tools only
- 🛑 **One command to stop** everything

---

## 📋 Requirements
- Kali Linux / Debian-based distro
- Bluetooth adapter enabled
- `sudo` privileges
